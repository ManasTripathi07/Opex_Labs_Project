# 📱 How to Use the System

Role-specific guides for using the Production Tracker.

---

## 👷 For Machine Operators

### **Logging a Shift:**

1. **Open shift entry page** on your phone
2. **See your assignment:**
   - Machine name (e.g., M-001)
   - Design (e.g., BUTTERFLY-004)
   - Pieces to complete
3. **Enter counter reading:**
   - Look at machine counter
   - Type current number
4. **Enter rounds (if any):**
   - If counter reset to zero, enter how many rounds
   - If no reset, leave at 0
5. **Click Submit**
6. ✅ **Done!** Everything else happens automatically

### **Tips:**
- Always log shifts on time (don't wait)
- Double-check counter readings before submitting
- Log rounds when counter resets
- Use your phone for quick entry

---

## 👔 For Supervisors

### **Creating a New Assignment:**

1. **Open Production page**
2. **Click "New Assignment" button**
3. **Fill in details:**
   - Select machine from dropdown
   - Select sub-lot from available list
   - Enter pieces to assign
4. **Click Create**
5. ✅ **Assignment is live!** Operators can start logging shifts

### **Monitoring Progress:**

1. **Check Dashboard regularly**
2. **Look at progress bars:**
   - Green bar shows completion percentage
   - Updates automatically as shifts are logged
3. **Review warnings in shift logs:**
   - Yellow warnings = suspicious but allowed
   - Red errors = need attention
4. **Generate reports at end of day:**
   - Daily Production Report
   - Salary Reports

### **Managing Assignments:**

- **Active** - Work in progress
- **Completed** - Automatically marked when 100% done
- **View Details** - Click row to see full history

---

## 📊 For Management

### **Viewing Factory Status:**

1. **Open Dashboard**
2. **Check KPI Cards:**
   - **Active Machines** - How many working now
   - **In Production** - Current work items
   - **Allocated** - Assigned but not started
   - **Completed Today** - Today's completions
3. **Review Active Assignments:**
   - See all machines and their progress
   - Click "Log Shift" to record for any machine
4. **Check Daily Production Report:**
   - Production by machine
   - Production by operator
   - Total output

### **Generating Reports:**

**Salary Reports:**
1. Go to Production page
2. Click operator name
3. Select date range
4. View detailed stitches and amounts

**Daily Production:**
1. Dashboard shows today's report automatically
2. Refresh page to update

## 📥 For Receiving Staff

### **Creating a New Lot:**

1. **Open Inbound page**
2. **Click "New Lot" button**
3. **Enter lot details:**
   - Lot number (e.g., LOT-2025-001)
   - Select client
   - Total pieces
   - Received date
4. **Split into sub-lots:**
   - Add row for each design
   - Select design
   - Enter piece count
   - Total must equal lot pieces
5. **Submit**
6. ✅ **Sub-lots are ready** for production assignment

### **Viewing Lots:**

- **Received** - Just entered, not assigned yet
- **Allocated** - Assigned to machines
- **In Production** - Work started
- **Completed** - All done
- **Dispatched** - Shipped out

## 🎯 Understanding the Workflow

### **Complete Journey of Work:**

```
1. 📥 ORDER ARRIVES
   └─ Receiving staff enters into Inbound

2. ✂️ SPLIT INTO SUB-LOTS
   └─ Divide by design

3. 🏭 ASSIGN TO MACHINES
   └─ Supervisor assigns in Production
   Status: "allocated" ✅

4. 👷 FIRST SHIFT LOGGED
   └─ Operator logs shift
   System automatically:
   ├─ Calculates pieces produced
   ├─ Updates progress
   └─ Changes status to "in_production" ✅

5. 📈 MORE SHIFTS
   └─ Operators continue logging
   System continuously updates progress

6. ✅ COMPLETION
   └─ When 100% reached:
   System automatically:
   ├─ Marks assignment "completed" ✅
   ├─ Records completion time
   └─ Updates dashboard counts

7. 📦 DISPATCH
   └─ Supervisor manually marks "dispatched"
```

**Everything in steps 4-6 happens AUTOMATICALLY!**

## 📱 Mobile Usage Tips

### **For Operators on Phones:**

- **Large touch targets** - Easy to tap buttons
- **Auto-filled data** - Previous counter pre-filled
- **Simple form** - Only enter what changed
- **Quick submit** - 30 seconds or less
- **Works offline** - Submit when internet returns

### **Best Practices:**

1. **Bookmark the shift entry page**
2. **Use portrait mode** for easier typing
3. **Double-tap to zoom** if numbers too small
4. **Submit immediately** after shift ends
5. **Check for green success** message

## 💡 Pro Tips

### **For Faster Data Entry:**

1. **Use Tab key** to move between fields
2. **Enter key** to submit forms
3. **Keyboard shortcuts** work in forms
4. **Auto-complete** remembers recent entries

### **For Better Accuracy:**

1. **Check counter twice** before submitting
2. **Verify design** matches actual work
3. **Confirm rounds** if counter reset
4. **Review warnings** before ignoring them

### **For Troubleshooting:**

1. **Refresh page** if data looks wrong
2. **Check internet** if submit fails
3. **Clear cache** if changes don't appear
4. **Hard refresh** - Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)

## 📞 Common Questions

**Q: Why isn't my shift showing up?**  
A: Refresh the dashboard. Changes appear within seconds.

**Q: Can I edit a submitted shift?**  
A: Contact supervisor to correct errors.

**Q: What if I enter wrong counter?**  
A: Submit shows error if impossible. Double-check reading.

**Q: How do I know what to produce?**  
A: Shift entry page shows your current assignment.

**Q: Can multiple operators log at once?**  
A: Yes! System handles concurrent shifts safely.
