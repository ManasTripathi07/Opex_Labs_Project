## ⚙️ What You Need to Do Before Deploying

### **Just 3 Things:**

#### **1. Get a Server**
Options:
- Buy a VPS (DigitalOcean, Linode, AWS)
- Use free tier (Railway, Render, Heroku)
- Use your own server

#### **2. Update 2 Configuration Files**

**File 1: `backend/.env`**
```env
Change this line:
CORS_ORIGIN=http://localhost:5173

To your website URL:
CORS_ORIGIN=https://your-website.com
```

**File 2: `frontend/src/api/client.js`**
```javascript
Change this line:
const API_BASE_URL = 'http://localhost:3000/api';

To your server URL:
const API_BASE_URL = 'https://your-api.com/api';
```

#### **3. Deploy**
- Upload code to server
- Install dependencies
- Run migrations
- Start the server
- Done!

## 💡 Easiest Deployment Method

### **Use Railway + Vercel (No Server Needed!)**

**Step 1: Deploy Backend (Railway)**
1. Create account on Railway.app
2. Click "New Project"
3. Connect your GitHub
4. Add PostgreSQL database (one click)
5. Set environment variables
6. Deploy! ✅

**Step 2: Deploy Frontend (Vercel)**
1. Create account on Vercel.com
2. Click "New Project"
3. Connect your GitHub
4. Set API URL in environment
5. Deploy! ✅

**Cost:** FREE for small usage!
